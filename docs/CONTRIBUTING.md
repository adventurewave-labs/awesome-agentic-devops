# Contributing

PRs welcome. To keep this list operator-grade:

1. **Relevance** — must be *agentic* DevOps: AI agents reasoning/acting on infrastructure, delivery, or operations. Generic AIOps dashboards and plain CI/CD automation are out of scope.
2. **Live links only** — verify the link resolves before submitting; note `⚠️ archived` entries explicitly rather than removing them (history matters).
3. **One-line operator description** — say what it *does*, not what it is called.
4. **Attribution** — if the entry came from another curated list or vendor page, keep the description honest and add the source to the Sources line if it's a new seed.
5. **Star counts** — optional; include as `⭐N.nk` with the date if you add one.

By contributing you agree your additions are MIT-licensed.
